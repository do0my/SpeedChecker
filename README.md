# HTTP Download Speed Checker

Консольный скрипт на Python для измерения скорости скачивания файлов по HTTP/HTTPS.

Выполняет 10 последовательных запросов, дожидается полной загрузки каждого ответа и рассчитывает статистику.

## Требования

- Python **3.8+**
- Используются только встроенные модули Python.
- Дополнительная установка зависимостей не требуется.

## Использование

Запустите скрипт, передав URL файла в качестве аргумента:

```bash
python speed_test.py "https://thumb.wikimedia.org/wikipedia/commons/thumb/f/ff/Pizigani_1367_Chart_10MB.jpg/960px-Pizigani_1367_Chart_10MB.jpg"
```

## Результаты измерений

После выполнения запросов скрипт выводит:

- Среднее время одного запроса (секунды).
- Общий объём скачанных данных (MB).
- Среднюю скорость скачивания (MB/s).

**Единицы измерения:**
- MB — мегабайт (1 MB = 1 000 000 байт).
- MB/s — мегабайт в секунду.

Скорость рассчитывается на основе общего объёма скачанных данных и суммарного времени выполнения запросов.
