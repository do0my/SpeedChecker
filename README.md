# HTTP Download Speed Checker

Консольный скрипт для замера скорости скачивания файла по HTTP/HTTPS. Выполняет серию последовательных запросов, дожидается полной загрузки тела ответа на каждом шаге и рассчитывает итоговую статистику.

## Требования

- Python **3.8+** (используются только встроенные модули стандартной библиотеки, установка пакетов через `pip` не требуется).

## Использование

Базовый запуск (выполнит 10 последовательных запросов):

```bash
python speed_test.py [https://example.com/large-image.jpg](https://example.com/large-image.jpg)
